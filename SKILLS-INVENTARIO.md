## Comando para buscar
npx skills find NOMBRE

## Formato para instalar una Skill
npx skills add PROPIETARIO/REPOSITORIO --skill NOMBRE-DE-LA-SKILL -a opencode

## Comprobar las Skills instaladas
npx skills list
npx skills list -g

## Advertencia
Este inventario contiene términos de búsqueda, no repositorios confirmados.
Antes de instalar, hay que identificar el repositorio real y el nombre exacto
de cada Skill en los resultados del catálogo.
